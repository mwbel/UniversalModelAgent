1.12.1. The Need for Pivoting

Suppose we wish to compute an LU factorization
$$A = \left[ \begin{array} { r r } 
\epsilon & - 1 \\
1 & 1
\end{array} \right] = \left[ \begin{array} { c c } 
1 & 0 \\
l _ { 21 } & 1
\end{array} \right] \left[ \begin{array} { c c } 
u _ { 11 } & u _ { 12 } \\
0 & u _ { 22 }
\end{array} \right] , \quad 0 < \epsilon \ll 1 .$$

Clearly, $u _ { 11 } = \epsilon , u _ { 12 } = - 1 , l _ { 21 } = \epsilon ^ { - 1 }$, and $u _ { 22 } = 1 - l _ { 21 } u _ { 12 } = 1 + \epsilon ^ { - 1 }$. In floating point arithmetic, if $\epsilon$ is sufficiently small then $\widehat { u } _ { 22 } = f l \left( 1 + \epsilon ^ { - 1 } \right)$ evaluates to $\epsilon ^ { - 1 }$. Assuming $l _ { 21 }$ is computed exactly, we then have
$$A - \widehat { L } \widehat { U } = \left[ \begin{array} { r r } 
\epsilon & - 1 \\
1 & 1
\end{array} \right] - \left[ \begin{array} { c c } 
1 & 0 \\
\epsilon ^ { - 1 } & 1
\end{array} \right] \left[ \begin{array} { c c } 
\epsilon & - 1 \\
0 & \epsilon ^ { - 1 }
\end{array} \right] = \left[ \begin{array} { l l } 
0 & 0 \\
0 & 1
\end{array} \right] .$$

Thus the computed LU factors fail completely to reproduce $A$. Notice that there is no subtraction in the formation of $\widehat { L }$ and $\widehat { U }$. Furthermore, the matrix $A$ is very well conditioned $\left( \kappa _ { \infty } ( A ) = 4 / ( 1 + \epsilon ) \right)$. The problem, of course, is with the choice of $\epsilon$ as the pivot. The partial pivoting strategy would interchange the two rows of $A$ before factorizing it, resulting in a stable factorization.
